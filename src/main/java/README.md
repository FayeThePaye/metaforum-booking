### Usage
- import ZIP to netbeans
- press Run Project (F6)
- enter student ID, and password. Then click create account.
- Create appointments by clicking Create Booking, clicking on the desired study room, 
and inputting the time and date for the booking.
- Cancel already made bookings by navigating back to the homepage, clicking Cancel Booking, 
selecting the appointment you want to cancel, and pressing the red cancel button.
- After you are done, navigate to homepage, and click logout.
